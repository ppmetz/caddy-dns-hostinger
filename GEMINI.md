# Auto Modus

- **Automatic Execution:** Always operate in "auto modus". When presented with a task, execute the necessary tool calls (e.g., file edits, commands, subagents) immediately.
- **Do Not Wait for Approval:** Do NOT stop and wait for explicit user approval before proceeding to execution, even in Planning Mode. 
- **Minimize Interruptions:** Do not bother the user with step-by-step permission requests. Proceed with your implementation plan autonomously and report back only when the work is complete, or if you encounter a blocking error that requires the user's intervention.
